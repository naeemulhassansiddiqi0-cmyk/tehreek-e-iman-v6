# تحریک ایمان — روزانہ نماز کے اوقات

**محمد نعیم الحسن صدیقی** کی جانب سے تیار کردہ ایک اسلامی ویب ایپلیکیشن، جو نماز کے اوقات، مسنون طریقے، اور روزمرہ اعمال کی تصدیق شدہ اسلامی معلومات ایک ہی جگہ فراہم کرتی ہے۔

🔗 **لائیو ویب سائٹ:** https://naeemulhassansiddiqi0-cmyk.github.io/tehreek-e-iman-v6/

---

## ✨ خصوصیات (Features)

- 📍 پاکستان کے 15 بڑے شہروں کے لیے روزانہ نماز کے اوقات (Aladhan API)
- 🕋 لائیو پاکستان اسٹینڈرڈ ٹائم (PST) گھڑی اور اگلی نماز کے لیے کاؤنٹ ڈاؤن ٹائمر
- 🔔 ہر نماز کے لیے الگ الگ الارم اور اذان کی سہولت
- 📖 ہر نماز پر کلک کرنے سے مکمل تفصیل:
  - فرض/سنت/نفل/وتر کی رکعات اور فقہ حنفی کے مطابق ترتیب
  - تصدیق شدہ احادیث (عربی متن + اردو ترجمہ + مکمل حوالہ)
  - نماز پڑھنے کا مکمل طریقہ — نیت سے سلام تک (تکبیر، ثناء، تعوذ، تسمیہ، سورۃ الفاتحہ، تشہد، درود، دعا)
- 🌙 اضافی اوقات و اعمال: سحری، افطاری، اشراق، چاشت، اوابین، تہجد، طلوعِ آفتاب، غروبِ آفتاب
- 🕌 نمازِ جنازہ کا مکمل طریقہ
- 🔊 ہر سیکشن کو "سنیں" — آواز میں سننے کی سہولت (عربی و اردو الگ الگ آواز میں)
- 🎨 صارف اپنی مرضی کے اوقات بھی شامل کر سکتا ہے (Custom Time)

## ⚠️ اہم نوٹ برائے صحتِ احادیث

اس سائٹ میں شامل ہر حدیث کے ساتھ حوالہ (کتاب اور حدیث نمبر) دیا گیا ہے۔
- ✓ کا نشان = مستند اور تصدیق شدہ حوالہ
- ⚠ کا نشان = عمومی فقہی نوٹ یا ایسا حوالہ جس کی مزید تصدیق درکار ہے

مکمل تسلی کے لیے ہمیشہ [sunnah.com](https://sunnah.com) یا Islam360 ایپ سے حوالہ کی مزید تصدیق کر لیں۔

## 🛠️ فنی تفصیلات (Technical)

- خالص HTML, CSS, JavaScript — کسی بیک اینڈ سرور کی ضرورت نہیں
- Aladhan API سے نماز کے اوقات
- Web Speech API سے آواز کی سہولت (سیکشن آڈیو فائلز کے ساتھ اپ گریڈ کیا جا سکتا ہے، دیکھیں نیچے)
- GitHub Pages پر مکمل مفت میزبانی
